# H_W_Slover
this app gives u shortcuts to make the mouse click on certain position fastly and accuratly ,
these positions can be set by the user,
this app is intended to help students deliver their h.w fastly and accuratly to save time. 

User Guide:
===> u can use the app default shortcuts and here it is:
1. 1 :a
2. 2 :b
3. 3 :c
2. 4 :d
3. Ctrl_left: next
===> or set the shortcuts by ur self by editing the main.py file
===> the app has four sections for each subject that u can set the clicker by ur self,
 just choose the subject then press 1 and enter to edit
